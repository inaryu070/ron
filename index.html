麻雀 捨て牌読みクイズ

天鳳鳳凰卓2009年の実戦牌譜から抽出したリーチ局面100問を内蔵しました。待ちはリーチ宣言時の手牌から完全復元し、手牌・4人の河・ドラ・副露をその局面の状態で再現します。
追加で天鳳XML / MJAI(.mjson/.jsonl)も直接読み込めます。

収録件数 0 現在 0 / 0 ソース 内蔵サンプル 実戦 0 品質A/B 0

使い方は3ステップだけ

① 問題を見る卓と自分の手牌を見る
② 切る牌を選ぶ自分の手牌を1枚タップ
③ 答えを見る右上の「答えを見る」を押す
標準で実戦100局面を出題します。待ち形は両面45 / カンチャン15 / ペンチャン10 / シャンポン20 / 単騎10に学習用として配分しています。
河は6枚切りベース。1段目は奥、2段目は中央、3段目は手前に並び、左右の牌は席方向に合わせて回転表示します。
問題： リーチに対して、あなたなら何を切りますか？ 手牌を1枚タップしてください。
答えを見ると、実際の危険牌 / 待ち / 打点 / AI推定 を比較できます。
普通に使うだけならJSONは気にしなくてOKです。天鳳の牌譜XMLを選ぶと、リーチ局面を自動抽出して問題に追加します。
